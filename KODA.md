# Rutube Downloader — KODA.md

## Назначение проекта

**Rutube Downloader** — это десктопное приложение с графическим интерфейсом на Python для скачивания видео с платформы Rutube. Приложение позволяет:
- Получать список всех видео с канала Rutube
- Просматривать метаданные видео (название, дата загрузки, длительность)
- Выбирать видео для скачивания
- Скачивать видео с параллельной загрузкой
- Сохранять превью и описания к видео
- Контролировать прогресс загрузки через GUI

## Технологии и зависимости

### Язык и фреймворки
- **Python 3.10+** — основной язык
- **Tkinter** — GUI фреймворк
- **Selenium** — получение списка видео с канала (headless Chrome)
- **yt-dlp** — получение метаданных и скачивание видео
- **requests** — загрузка изображений (превью)

### Зависимости (requirements.txt)
```
yt-dlp
requests==2.32.5
selenium==4.38.0
webdriver-manager==4.0.2
colorama==0.4.6
```

## Архитектура проекта

Проект построен в стиле **OOP + модульная архитектура**. Каждый модуль отвечает за отдельную область функциональности:

### Структура файлов

```
.
├── main.py                    # Точка входа
├── requirements.txt           # Зависимости
├── start.cmd                  # Скрипт запуска для Windows
├── rutube_config.json         # Файл настроек приложения
└── app/
    ├── __init__.py
    ├── rutube_gui.py          # GUI и обработчики действий пользователя
    ├── rutube_downloader.py   # Оркестрация загрузки, RutubeDownloader
    ├── rutube_gateway.py      # Работа с Rutube: Selenium + yt-dlp
    ├── rutube_storage.py      # Работа с файлами, сохранение данных
    ├── rutube_models.py       # Модели данных (VideoMetadata, AppSettings, DownloadStatus)
    ├── rutube_config.py       # Загрузка и сохранение настроек
    └── rutube_logger.py       # Логирование в файл, консоль и GUI
```

### Описание модулей

#### `main.py`
Точка входа в приложение. Инициализирует:
- Логгер с файлом логов
- Менеджер конфигурации
- Хранилище (LocalStorage)
- Шлюз (RutubeGateway)
- Загрузчик (RutubeDownloader)
- GUI (RutubeGUI)

#### `app/rutube_gui.py` — GUI и обработчики
- Создает интерфейс на Tkinter с таблицей видео, прогресс-баром и консолью логов
- Обработчики: получить список, скачать, остановить, настройки
- Потоковая передача статусов через `widget.after()`
- Поддержка сортировки по колонкам
- Двойной клик для открытия скачанного видео

#### `app/rutube_downloader.py` — Оркестрация загрузки
- Класс `RutubeDownloader` связывает Gateway и Storage
- Метод `get_channel_videos()` — получение списка и метаданных
- Метод `download_videos()` — параллельная загрузка через `ThreadPoolExecutor`
- Механизм отмены загрузки через флаг `_cancel_flag`
- Интеграция `yt-dlp` через кастомный логгер и progress hooks

#### `app/rutube_gateway.py` — Работа с Rutube
- `RutubeGateway` — шлюз для взаимодействия с Rutube
- `fetch_channel_videos()` — получение списка видео через Selenium (headless Chrome с автоустановкой через webdriver-manager)
- `fetch_metadata_list()` — получение метаданных через yt-dlp с кэшированием в `metadata.json`
- Автоматическая прокрутка страницы для сбора всех ссылок
- Повторные попытки при ошибках получения метаданных

#### `app/rutube_storage.py` — Работа с файлами
- Создание папок каналов
- Сохранение метаданных в CSV и JSON
- Загрузка и сохранение превью (jpg)
- Сохранение описаний (txt)
- Проверка существования файлов
- Открытие файлов через системные команды

#### `app/rutube_models.py` — Модели данных
- `VideoMetadata` — данные о видео (id, название, URL, дата, длительность, описание, превью)
- `ChannelInfo` — информация о канале (URL, имя)
- `AppSettings` — настройки приложения (папка загрузок, количество потоков)
- `DownloadStatus` — статусы загрузки (PENDING, DOWNLOADING, COMPLETED, FAILED, CANCELLED, SKIPPED)
- `sanitize_filename()` — очистка названий файлов от недопустимых символов

#### `app/rutube_config.py` — Конфигурация
- `ConfigManager` — загрузка/сохранение настроек в `rutube_config.json`
- Хранит: последнюю URL, папку загрузок, количество параллельных загрузок и фрагментов

#### `app/rutube_logger.py` — Логирование
- `AppLogger` — кастомный логгер с RotatingFileHandler
- Логирование в файл, консоль и GUI
- `TkTextHandler` — вывод логов в Tkinter Text виджет с цветовой подсветкой уровней

## Правила разработки

### Стиль кодирования
- **OOP подход** — каждый модуль инкапсулирует свою логику
- **Dataclasses** — для моделей данных (`@dataclass(frozen=True)`)
- **Type hints** — аннотации типов для всех функций и методов
- **Строгая типизация** — использование `| None`, `Callable`, `Path`

### Архитектурные паттерны
- **Separation of Concerns** — четкое разделение GUI, логики, доступа к данным
- **Dependency Injection** — компоненты передаются в конструкторы
- **Callback-паттерн** — передача функций для прогресса и статусов
- **Thread safety** — использование `threading.Lock` для флагов отмены

### Правила работы с GUI
- GUI не должен напрямую работать с Selenium или yt-dlp
- Все длительные операции выполняются в отдельных потоках
- Обновления GUI делаются через `widget.after()` для thread-safety

### Правила логирования
- Логирование в файл с ротацией (10 MB, 5 бэкапов)
- Логирование в консоль и GUI виджет
- Цветовая подсветка уровней в GUI

### Обработка ошибок
- Повторные попытки при ошибках сети (yt-dlp metadata fetch)
- Graceful shutdown при отмене загрузки
- Обработка исключений в каждом потоке

## Конфигурация

Файл `rutube_config.json`:
```json
{
  "last_url": "https://rutube.ru/channel/43480214/videos/",
  "download_folder": "G:\\iven\\Yandex.Disk\\0_Проекты\\rutube_downloads",
  "concurrent_fragment_count": 4,
  "max_workers": 4
}
```

| Параметр | Описание |
|----------|----------|
| `last_url` | Последняя использованная ссылка на канал |
| `download_folder` | Корневая папка для загрузок |
| `concurrent_fragment_count` | Количество параллельных фрагментов для одного видео (yt-dlp) |
| `max_workers` | Количество параллельных загрузок видео |

## Логирование

- Файл: `rutube_app.log` в корневой директории
- Формат: `[YYYY-MM-DD HH:MM:SS] LEVEL MESSAGE`
- Ротация: при достижении 10 MB, до 5 бэкапов

## Ключевые особенности реализации

### Получение списка видео
1. Selenium открывает страницу канала в headless режиме
2. Автоматическая прокрутка страницы для подгрузки контента
3. Сбор всех ссылок на видео через CSS-селекторы
4. Нормализация URL (добавление `/` в конце)

### Скачивание видео
1. yt-dlp с кастомным логгером и progress hooks
2. Параллельная загрузка через ThreadPoolExecutor
3. Поддержка отмены загрузки на уровне фрагментов
4. Автоматическая постобработка (сборка файла, обложки)

### Форматирование файлов
- Имя файла: `ГГГГ.ММ.ДД_ЧЧ.ММ_Название видео.mp4`
- Сохранение: описание в `.txt`, превью в `.jpg`, метаданные в `.csv` и `.json`

## Известные ограничения

- Требуется установленный Chrome/Chromium для Selenium
- headless режим может не работать на некоторых системах без виртуального дисплея
- yt-dlp требует актуальных обновлений для поддержки Rutube
