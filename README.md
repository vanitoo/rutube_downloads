# Rutube Downloader

Десктопное приложение для скачивания видео с платформы Rutube с графическим интерфейсом.

## Возможности

- Получение списка всех видео с канала Rutube
- Просмотр метаданных видео (название, дата загрузки, длительность)
- Выбор видео для скачивания
- Параллельная загрузка нескольких видео
- Сохранение превью и описаний к видео
- Контроль прогресса загрузки через GUI
- Сортировка видео по колонкам
- Отмена загрузки в любой момент

## Технологии

- **Python 3.10+**
- **Tkinter** — GUI фреймворк
- **Selenium** — получение списка видео с канала (headless Chrome)
- **yt-dlp** — получение метаданных и скачивание видео
- **requests** — загрузка изображений (превью)

```
.
```

## Установка и запуск

### Через терминал

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### Через start.cmd (Windows)

Просто запустите `start.cmd` — скрипт автоматически:
1. Создаст виртуальное окружение `.venv`
2. Активирует его
3. Установит зависимости
4. Запустит `main.py`

## Настройки

Настройки хранятся в `rutube_config.json`:

| Параметр | Описание |
|----------|----------|
| `last_url` | Последняя использованная ссылка на канал |
| `download_folder` | Корневая папка для загрузок |
| `concurrent_fragment_count` | Количество параллельных фрагментов для одного видео (yt-dlp) |
| `max_workers` | Количество параллельных загрузок видео |

## Формат файлов

- **Видео**: `ГГГГ.ММ.ДД_ЧЧ.ММ_Название видео.mp4`
- **Описание**: `ГГГГ.ММ.ДД_ЧЧ.ММ_Название видео.txt`
- **Превью**: `ГГГГ.ММ.ДД_ЧЧ.ММ_Название видео.jpg`
- **Метаданные**: `metadata.csv` и `metadata.json`

## Известные ограничения

- Требуется установленный Chrome/Chromium для Selenium
- headless режим может не работать на некоторых системах без виртуального дисплея
- yt-dlp требует актуальных обновлений для поддержки Rutube
